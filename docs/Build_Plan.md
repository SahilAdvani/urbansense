# UrbanSense - Build Plan

## Project Timeline

**Start Date:** 1 July 2026

**Submission Deadline:** 21 July 2026

**Team Size:** 2 Developers

---

# MVP Goal

Build a functional AI-powered Urban Air Quality Intelligence platform that allows municipal administrators to:

- Monitor city-wide air quality
- Visualize pollution on an interactive map
- Analyze pollution hotspots
- Forecast AQI
- Receive AI-generated intervention recommendations
- Generate citizen advisories
- Export reports
